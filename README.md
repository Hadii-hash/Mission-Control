# 🛰️ Mission Control

**An interactive, space-themed 3D portfolio built to explore the intersection of web development and immersive experiences.**

🌐 **Live Demo:** [mission-control-tiqv.vercel.app](https://mission-control-tiqv.vercel.app/)

## 🌌 Overview

Mission Control is a personal portfolio inspired by a futuristic space mission interface. Instead of a conventional portfolio layout, it uses an interactive 3D environment to create a more immersive way to explore projects and contact the developer.

## ✨ Features

* 🪐 Interactive 3D space environment
* 🛰️ Clickable satellite interaction
* 📡 Interactive contact panel
* ✉️ Contact form with email functionality
* 🌐 Live deployment with Vercel
* 🎨 Custom styling and animated interface

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Three.js
* Vite
* Node.js and Express
* Resend for email delivery
* Vercel

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Hadii-hash/Mission-Control.git
cd Mission-Control
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Follow the local URL printed in your terminal.

## ⚙️ Environment Variables

If you run the email backend locally, configure the required environment variables in a `.env` file. Keep API keys private and never commit your `.env` file to GitHub.
